1. PROJECT OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Apex is a fully autonomous AI sales agent for CoreFlow Pilates Studio.
It cold-calls leads, qualifies them live, handles product objections
with real-time semantic search, closes verbally, then automatically sends
a personalized follow-up email with a Stripe payment link — all with zero
human involvement.

Every step of the sales loop is tracked on a live React dashboard via
Server-Sent Events (SSE).

  Demo persona : Maya (AI voice agent)
  Demo lead    : Sarah K. · +17143101206 · quachphuwork@gmail.com
  Demo product : $30 beginner trial class · CoreFlow Pilates · Santa Monica
  Demo goal    : Complete a full cold-call → qualify → close → pay loop
                 demonstrable in under 90 seconds

6.2  prompts.py  —  Maya's personality and sales script
────────────────────────────────────────────────────────────

  MAYA_SYSTEM_PROMPT
    · Python format string — three placeholders injected at runtime:
        {current_stage}    — from infer_stage()
        {turn_count}       — from call_state["turn_count"]
        {has_closed}       — from call_state["has_closed"]

  6 STAGE DEFINITIONS embedded in the prompt:

    Stage 1 — INTRO
      Exact line: "Hi! This is Maya calling from CoreFlow Pilates in
      Santa Monica. I'll keep it super quick — have you ever tried
      pilates before, or would this be your first time?"

    Stage 2 — QUALIFY
      Branches on YES / NO / unclear. Each branch has exact scripted text.

    Stage 3 — PITCH
      Max 2 sentences. Answers questions from product knowledge, redirects
      to "Would Saturday morning at 10 AM work for you?"

    Stage 4 — CLOSE
      Exact line: "I'd love to lock in that Saturday 10 AM spot for you.
      Can I send a quick payment link to your email?"

    Stage 5 — CONFIRMED
      Outputs one of two scripted closing lines + [CALL_COMPLETE] token.
      No further engagement permitted.

    Stage 6 — DECLINED
      Offers to send info by email. Wraps up politely.

  10 ABSOLUTE RULES in the prompt:
    1. Never repeat a question already asked
    2. Never repeat a pitch already made
    3. Never re-engage after [CALL_COMPLETE]
    4. No medical claims
    5. Never negotiate below $25
    6. 1–3 sentences maximum per response
    7. Garbled input → "Sorry, you broke up — are you still there?"
    8. Off-topic → redirect to CoreFlow trial
    9. No markdown/asterisks/bullets — spoken words only
    10. Post-close utterance → one wrap-up then stop

  MAYA_BEGIN_MESSAGE
    · Static string used as the greeting when the call connects
    · "Hi! This is Maya calling from CoreFlow Pilates in Santa Monica..."

  PRODUCT KNOWLEDGE embedded in prompt (7 categories):
    Pricing, Schedule, Location, Pilates vs Yoga, Instructor,
    Cancellation, Price Objection Scripts

6.3  voice_handler.py  —  Core voice turn logic
────────────────────────────────────────────────────────────

  GEMINI CLIENT
    · Lazy singleton: get_gemini_client()
    · Uses: genai.Client(api_key=GEMINI_API_KEY)
    · SDK: google-genai (new Google SDK pattern, not google-generativeai)
    · Wrapped in try/except import — GEMINI_AVAILABLE flag set to False
      if SDK missing

  MOSS_TRIGGERS (50+ keywords in 8 categories)
    Pricing, Schedule, Location, Pilates vs Yoga, Beginner, Instructor,
    Cancellation, Price Objection

  IGNORE_PATTERNS (8 patterns)
    Off-topic phrases that should not trigger Moss:
    "pirate", "engineer", "are you a robot", "are you ai", etc.

  should_query_moss(text) → bool
    · Returns False immediately if any IGNORE_PATTERN matches
    · Returns True if any MOSS_TRIGGER keyword matches

  _is_garbled(text) → bool  (3 checks)
    1. Empty or length < 2
    2. Single filler words: "um", "uh", "hmm", "ok", "yeah", "mhm"
    3. len(words) <= 2 AND len(text) < 5
    4. Repetition ratio: unique words < 40% of total words

  _fallback_response(caller_text, moss_context, current_stage) → str
    · Priority 1: Use moss_context first sentence if available
    · Priority 2: Detect yes/no intent in caller_text
    · Priority 3: Stage-specific canned response map

  emit_event(event_type, data) → async
    · Puts {"type": event_type, "data": data} onto call_state["sse_queue"]
    · Silently no-ops if queue is None

  handle_voice_turn(caller_text, recent_history) → AsyncGenerator[bytes]
    Full execution sequence per turn:

    Guard 1   call_complete == True
              → yield "You're all set! Have a great day!" → return

    Guard 2   has_closed == True
              → yield wrap-up line → set call_complete=True → return

    Guard 3   _is_garbled(caller_text)
              → yield "Sorry, you broke up there" → return

    Step 1    Increment turn_count, append lead turn to transcript,
              emit SSE transcript event

    Step 2    If turn_count > 2: yield random interim filler
              ["Let me check that.", "Great question.", "Sure!", "Absolutely."]
              (prevents dead silence while async work runs)

    Step 3    If should_query_moss(caller_text):
              → await query_moss() → store result + latency
              → emit SSE moss_query event
              → set pipeline["objection_handled"] = True
              → increment objection_count

    Step 4    If lead set: await recall_lead(phone)
              → if result: store in memory_recall, emit SSE memory_recall

    Step 5    current_stage = infer_stage(transcript, has_closed)

    Step 6    Build system_with_stage:
              MAYA_SYSTEM_PROMPT.format(stage, turn_count, has_closed)
              + append moss_context if present
              + append memory_context if present

    Step 7    Build Gemini contents list:
              For each transcript turn (except last):
                role "agent" → "model", role "lead" → "user"
                Wrap in genai_types.Content(role, parts=[Part(text)])
              Append current caller_text as final user Content

    Step 8    Call Gemini:
              gemini_client.models.generate_content(
                model="gemini-2.0-flash",
                contents=contents,
                config=GenerateContentConfig(
                  system_instruction=system_with_stage,
                  max_output_tokens=120,
                  temperature=0.5
                )
              )
              Run in executor (thread pool) to avoid blocking event loop
              Strip *, #, _ from response

    Step 9    If no agent_text: use _fallback_response()

    Step 10   If "[CALL_COMPLETE]" in agent_text:
              → strip token → set has_closed=True, call_complete=True
              → asyncio.create_task(trigger_post_call_pipeline())

    Step 11   If close signals in agent_text and not already closed:
              → set has_closed=True
              → asyncio.create_task(trigger_post_call_pipeline())
              Close signals: "sending that to your email", "sending the link",
              "see you saturday", "you're all set", "check your email",
              "looking forward to seeing you"

    Step 12   Append agent turn to transcript, emit SSE transcript event

    Step 13   yield final NDJSON: {"text": agent_text}

  trigger_post_call_pipeline() — async background task
    1. asyncio.sleep(1.5)  — let TTS finish speaking
    2. create_payment_link(email, 3000, description) → payment_url
    3. send_followup(to_email, lead_name, payment_url)
    4. If email sent: set pipeline["email_sent"]=True, emit SSE events

  handle_call_ended(call_id, body) — async
    1. store_call(phone, name, transcript, qualified, notes)
    2. If stored: pipeline["memory_saved"]=True, emit SSE pipeline_update
    3. status = "ended", emit SSE call_ended with durationSeconds

11. CONVERSATION STATE MACHINE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  State transitions (infer_stage is called on every voice turn):

    INTRO ──────────────→ QUALIFY  (after turn 1–2)
    QUALIFY ────────────→ PITCH    (after turn 3–4)
    PITCH ──────────────→ CLOSE    (after turn 5+)
    CLOSE ──────────────→ CONFIRMED (has_closed = True)
    Any stage ──────────→ DECLINED  (if hard "no" detected by Gemini)

  Guard rails in handle_voice_turn (checked in order before any logic):
    Guard 1: call_complete == True  → return fixed "all set" line
    Guard 2: has_closed == True     → return wrap-up line, set call_complete
    Guard 3: _is_garbled()          → return "you broke up" line

  [CALL_COMPLETE] token lifecycle:
    · Gemini outputs token when stage=CONFIRMED and lead says yes
    · Token stripped from speech before TTS
    · call_state["has_closed"] = True
    · call_state["call_complete"] = True
    · asyncio.create_task(trigger_post_call_pipeline()) — non-blocking

12. VOICE TURN TIMING  (per utterance, target <500ms)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  t=0ms    AgentPhone STT finishes → POST /webhook/voice arrives
  t=1ms    Guard checks (garbled / closed) — return immediately if triggered
  t=2ms    turn_count++, transcript.append, emit SSE
  t=3ms    If turn > 2: yield interim filler ({"text":..., "interim":true})
           AgentPhone TTS starts speaking filler immediately
  t=5ms    If should_query_moss(): await query_moss()
           Moss native SDK: <10ms · keyword fallback: <1ms
           Emit moss_query SSE event
  t=10ms   await recall_lead(phone) — Supermemory API call
           Returns "" on first call, profile on subsequent calls
  t=15ms   infer_stage() — O(1) based on transcript length
  t=20ms   Build system_with_stage string (format + append context)
  t=30ms   Build genai_types.Content list from transcript history
  t=50ms   run_in_executor → Gemini 2.0 Flash generate_content
  t=200ms  Strip markdown from response
  t=205ms  Check for [CALL_COMPLETE] token, close signals
  t=210ms  Append agent turn, emit SSE transcript event
  t=215ms  yield final NDJSON → AgentPhone TTS speaks response

17. AGENTPHONE API CALLS  (complete list used in main.py)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  All calls use:
    base URL: https://api.agentphone.ai
    header:   Authorization: Bearer {Agent_phone_key}
    client:   httpx.AsyncClient(timeout=30)

  1. POST /v1/agents
     Create Maya agent (only on first campaign)
     Body: {name, voiceMode:"webhook", beginMessage, voice:"Polly.Joanna",
            sttMode:"accurate", ambientSound:"office"}
     Response: {id, ...} → stored in _apex_agent_id

  2. POST /v1/webhooks
     Register webhook endpoint for voice events
     Body: {url: WEBHOOK_URL + "/webhook/voice", contextLimit: 10}

  3. GET /v1/numbers
     Fetch provisioned phone numbers
     Response: {data: [...]} or {items: [...]}

  4. POST /v1/numbers
     Provision new US number (only if none exist)
     Body: {country: "US"}
     Response: {id, ...}

  5. POST /v1/agents/{agentId}/numbers
     Attach phone number to agent
     Body: {numberId: number_id}

  6. POST /v1/calls
     Initiate outbound call
     Body: {agentId, toNumber, initialGreeting, voice: "Polly.Joanna"}
     Response: {id, ...} → stored in call_state["call_id"]

  Webhook events received from AgentPhone:
    · event: "agent.message", channel: "voice"
      data.transcript — lead utterance text
    · event: "agent.call_ended"
      data.durationSeconds — call length in seconds

18. KNOWN ISSUES & PRODUCTION NOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Issue                        Notes
  ─────────────────────────────────────────────────────────────────────────
  In-memory state              call_state is a plain dict — not persisted.
                               Restart loses all state. Use Redis or
                               a DB for production multi-tenant use.

  Single lead hardcoded        LEADS = [{...}] in main.py.
                               Production would load from CRM / CSV / API.

  No auth on API routes        All endpoints open. Add OAuth/API keys.

  No Stripe signature verify   Add stripe.Webhook.construct_event() for
                               production to prevent spoofed webhooks.

  Moss SDK dependency          inferedge-moss-core not reliably on PyPI.
                               Keyword fallback compensates for demo.
                               Check moss.dev for native install path.

  AgentPhone agent reuse       _apex_agent_id is module-level — reused
                               across calls. Fine for demo, but needs
                               proper lifecycle management in production.

  asyncio.get_event_loop()     Deprecated pattern for run_in_executor.
                               Use asyncio.get_running_loop() in Python 3.10+
                               for production code.

  CORS allow_origins=["*"]     Open for demo. Restrict to specific origins
                               in production.

  ngrok free tier              URL changes on each session. Use ngrok paid
                               or a fixed domain (e.g., Railway, Render)
                               for reliable webhook URLs.
